# Comece aqui

1. Leia [`USO-RESPONSAVEL.md`](USO-RESPONSAVEL.md) (2 minutos).
2. Teste o kit: `python3 -m unittest discover -s kit/testes -v` → tudo `OK`.
3. Descubra o seu quadrante: `python3 kit/scripts/quadrante.py`.
4. Siga os guias na ordem:
   - [1 · Quadrante](guias/1-quadrante.md)
   - [2 · Local](guias/2-local.md)
   - [3 · Sempre ligada](guias/3-sempre-ligada.md)
   - [4 · Voz com o Jarvis](guias/4-voz-jarvis.md)
5. Prefere que um assistente faça? Use os prompts em [`prompts/`](prompts/), um de cada vez.

Os comandos funcionam a partir da pasta raiz do projeto (a que tem o `README.md`).
